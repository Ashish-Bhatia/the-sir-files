The signed extension is inspected. Actual Gazette publication remains open. Read the primary-record follow-up.

The timetable must have one authoritative version

Original ECI Annexure VI envisaged an October 7 final roll. Later instructions superseded that schedule. Before advising any applicant, the latest signed order and the required notification must be checked; a cached district page does not settle the matter.

A data error is not automatically a deletion

Reporting described approximately 2.7 lakh anomalous ages, concentrated in some Nashik constituencies. The meaningful question is not just whether the data were corrected, but whether incorrect values triggered unnecessary notices or changed any ERO decision.

What would establish impact

A complete incident report would connect each affected record to its source value, ETL transformations, notice history, corrected value and final registration status.

What is still unknown

  • Locate the actual State Gazette issue publishing the 12 October notification; the signed notification itself has now been obtained.
  • Were any decisions affected by the alleged 1900 birth-year defaults?
  • Can ERO decisions be reconciled with final roll supplements?
The published records do not establish whether every individual decision was correct.
